# ПОСЛЕДНИЙ СИГНАЛ — LAST SIGNAL

Многопользовательская игра на выживание и социальную дедукцию. Убежище переполнено, вокруг катастрофа, а мест в капсуле меньше, чем желающих.

## Скриншоты

Скриншоты появятся после запуска интерфейса в браузере.

## Возможности

- Комнаты на 3 или 6–12 игроков, публичные и закрытые паролем. В игре втроём каждый получает две карты.
- Серверные фазы игры, раскрытие карт, чат и тайное голосование.
- Обычный режим и режим с тайным саботажником.
- Интерфейс на русском, адаптация для телефона, переподключение по токену.
- Встроенный каталог профессий, характеров, необычного багажа, тайн и катастроф.

## Технологии и требования

Node.js 20+, npm, Express, Socket.IO, HTML/CSS и JavaScript ES-модули. Данные комнат находятся в памяти сервера. База данных и платные API не нужны.

## Структура

`server.js` — HTTP/Socket.IO; `src/` — правила, проверка ввода, безопасность, комнаты, карты и таймеры; `public/` — интерфейс; `tests/` — тесты; `docs/` — инструкции.

## Быстрый запуск

1. Установите Node.js LTS.
2. Скачайте ZIP или клонируйте репозиторий.
3. Откройте терминал в папке проекта.
4. Установите зависимости: `npm install` (или `npm ci`, если lock-файл корректен).
5. Запустите проверки: `npm test`.
6. Запустите игру: `npm start`.
7. Откройте `http://localhost:3000`.

Фактический порт может отличаться, если задана переменная `PORT`.

### Windows

Распакуйте архив, в проводнике откройте папку проекта, в адресной строке напишите `cmd`, затем выполните `npm install` и `npm start`.

### Linux / macOS

Откройте терминал в проектной папке и выполните `npm install && npm start`.

### GitHub Codespaces

Загрузите проект в GitHub, нажмите Code → Codespaces → Create codespace, затем в терминале выполните `npm install` и `npm start`. В Ports откройте порт 3000. Закрытие Codespace остановит игру.

### GitHub

Создайте пустой репозиторий, распакуйте ZIP и загрузите файлы через веб-интерфейс GitHub либо выполните `git init`, `git add .`, `git commit -m "Add Last Signal game"` и `git push` после настройки удалённого репозитория.

## Тесты и проверки

`npm test` запускает тесты Node.js. `npm run check` проверяет структуру и минимальное число карт.

## Настройки окружения

Скопируйте `.env.example` в `.env` при необходимости и задайте `PORT`, `RECONNECT_GRACE_MS` или `ROOM_IDLE_MS`. Сам сервер читает `PORT` и `RECONNECT_GRACE_MS`; `.env` автоматически не загружается, переменные задаются платформой или оболочкой. Не публикуйте секреты.

## Публикация

Размещайте приложение на Node.js-хостинге с поддержкой WebSocket. Укажите `npm start`, включите публичный доступ, проверьте `/health` и протестируйте двумя клиентами. GitHub Pages не может запустить сервер Socket.IO. Подробности: [развёртывание](docs/DEPLOYMENT.md).

## Известные ограничения и безопасность

Комнаты хранятся только в памяти. Код версии 1 не сохраняет историю после перезапуска. Сессии представлены случайными секретными токенами; не передавайте их и не публикуйте пароли комнат. Подробные ограничения описаны в правилах. Сообщения экранируются в браузере.

Правила проекта: [правила игры](docs/GAME_RULES.md), [устранение неполадок](docs/TROUBLESHOOTING.md), [вклад](CONTRIBUTING.md), [безопасность](SECURITY.md). Лицензия — MIT.

### Игровая механика

Капсула имеет фиксированную вместимость, поэтому перед началом понятно точное число исключений. Игроки сами решают, кого оставить вне эвакуации, голосуя после обсуждения открытых карт. Карты служат аргументами, а не скрытыми очками; саботажник побеждает, если попадает в капсулу. Состояние комнат не сохраняется после остановки сервера.
