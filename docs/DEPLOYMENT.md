# Развёртывание

GitHub хранит исходный код, но сам по себе не запускает Node.js. GitHub Pages и другой статический хостинг не поддерживают сервер Socket.IO. Используйте Node.js-хостинг, который запускает `npm start` и проксирует WebSocket.

1. Импортируйте репозиторий в сервис Node.js.
2. Установите Node.js 20 или новее; команда сборки не нужна, команда запуска — `npm start`.
3. Передайте переменную `PORT`, если платформа её требует (обычно платформа задаёт её автоматически). Сервер слушает `0.0.0.0`.
4. Откройте публичный URL сервиса и проверьте `/health`; ответ должен содержать `{"status":"ok"}`.
5. Посмотрите журналы запуска в панели сервиса и откройте игру одновременно в двух браузерах.

В Codespaces откройте вкладку Ports, найдите порт 3000 и установите видимость Public, если приглашаете друзей. Оставьте Codespace запущенным: при остановке среды игра отключится. На бесплатных тарифах могут быть лимиты и сон приложения. Игровые комнаты находятся в памяти и теряются при перезапуске процесса.
