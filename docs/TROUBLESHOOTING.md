# Если что-то не работает

- `node` или `npm` не распознаны: установите Node.js LTS с npm, перезапустите терминал и проверьте `node -v` и `npm -v`.
- Ошибка `npm install`: проверьте интернет, затем повторите `npm install`. При наличии корректного lock-файла используйте `npm ci`.
- Нет сценария запуска: откройте терминал в корне проекта и запустите `npm start`.
- `EADDRINUSE`: порт занят; запустите `PORT=3001 npm start` (в PowerShell: `$env:PORT=3001; npm start`).
- Не открывается `localhost`: убедитесь, что сервер запущен; откройте `http://localhost:3000` на том же устройстве.
- Не работает Socket.IO/CORS/WebSocket: проверьте, что прокси поддерживает WebSocket и подключение идёт по тому же публичному адресу.
- Неверный пароль или комната заполнена: проверьте код и пароль у ведущего; запущенная игра не принимает новых участников.
- Телефон не видит компьютер: используйте IP компьютера в локальной сети, например `http://192.168.1.20:3000`; разрешите Node.js в брандмауэре. Телефон и компьютер должны быть в одной Wi-Fi сети.
- Порт Codespaces закрыт: откройте Ports, добавьте 3000 и скопируйте Forwarded Address.
- Сервер остановился после закрытия облачной среды: снова запустите `npm start` и не закрывайте среду во время игры.
- GitHub Pages не запускает backend Node.js. Разместите приложение на Node.js-хостинге.
- Комнаты пропали: активное состояние хранится в памяти и сбрасывается при перезапуске.
